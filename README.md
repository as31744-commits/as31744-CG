# Computer Graphics (CCS601) - Three.js

Ushtrimet nga ligjeratat (kopje e repos [cg-ccs601-2026](https://github.com/visarshehu/cg-ccs601-2026)) dhe detyrat e shtepise.

## Struktura

| Folderi | Permbajtja |
| --- | --- |
| `java i/` | Ushtrimi baze: kubi qe rrotullohet |
| `java i/detyra - shtepia/` | **Detyra 1:** shtepi e ndertuar me primitive (kuti, cilinder, kon) |
| `java ii/` | Kubi dhe sfera me drita dhe OrbitControls |
| `java ii/detyra - sistemi solar/` | **Detyra 2:** sistemi solar me planetin Mars dhe satelitin Phobos |
| `java iii/solar system/` | Sistemi solar: Dielli, Toka, Hena |
| `java iii/robotic arm/` | Dora robotike |
| `java iii/detyra - dora robotike/` | **Detyra 3:** dora robotike me gishta me madhesi te ndryshme qe levizin, dhe gishtin e madh ne anen e majte te shputes |

## Si te ekzekutohet

```bash
npm install
npx vite
```

Pastaj hapni ne shfletues folderin perkates, p.sh. `http://localhost:5173/java i/detyra - shtepia/`.

### Kontrollet e dores robotike (Detyra 3)

- `Q` / `A` - supi, `W` / `S` - berryli, `E` / `D` - kyçi
- `1` - `5` - hap/mbyll gishtin perkates (1 = gishti i madh ... 5 = i vogli)
- `R` - mbyll grushtin, `F` - hap doren
